# Community

GitHub Discussions is where people comment and where we reply, so the conversation stays in one place for everyone to see.

- **One discussion per journal entry.** Each entry ends with a link: "Talk about this entry".
- **Four discussion areas:** Welcome (introduce yourself), Ideas, Questions, and Show and tell.
- **Bugs and code changes** go to Issues.
- **Replying:** we aim to answer within a few days, thank people for every idea, and say plainly when something will or won't be done.
- **Behaviour:** our values are the house rules. Anyone who is disrespectful, especially about culture, gets one warning, then is removed.
